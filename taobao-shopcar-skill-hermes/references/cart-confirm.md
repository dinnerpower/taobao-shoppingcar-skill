# 加购确认与弹窗处理

## 点击"加入购物车"后可能的情况

### 1. 成功 ✅

页面出现确认信息：
- "已成功加入购物车"
- 弹窗显示商品缩略图 + "去购物车结算" 按钮
- 无需额外操作，告知用户即可

### 2. 未选规格 ⚠️

弹窗提示：
- "请选择商品属性"
- "请先选择颜色分类"
- "请选择规格"

**处理**：回到 SKU 选择步骤，补选缺失的规格。

### 3. 库存不足 ❌

提示：
- "该商品库存不足"
- "已售罄"
- "暂时缺货"

**处理**：告知用户商品无货。

### 4. 需要登录 🔐

跳转到登录页或弹出登录框。

**处理**：告知用户需要登录，引导手动完成。

### 5. 数量超限 ⚠️

提示：
- "超出限购数量"
- "每人限购 N 件"

**处理**：告知用户限购规则，调整数量重试。

### 6. 定金/预售商品 📦

按钮可能是：
- "付定金"
- "加入购物车（预售）"

**处理**：告知用户这是预售商品，加购流程可能不同。

## 弹窗检测命令

```bash
openclaw browser snapshot
```

在 snapshot 中查找弹窗特征：
- `[class*="dialog"]` / `[class*="modal"]` — 弹窗
- `[class*="toast"]` / `[class*="tip"]` — 提示信息
- `[class*="confirm"]` / `[class*="success"]` — 确认/成功
